# 电商系统 2 · BossShopImage 商品运营系统

织造台面向商品运营团队。供应商资料经过核对后形成商品档案和销售规格，每个规格可以建立独立母稿、销售图片和详情图。运营人员在同一工作台维护刊登资料、库存、订单和售后状态，查看平台回执和仍待处理的事项。

## 在 Windows 上运行

安装 Python 3.14，在仓库目录打开 PowerShell。

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\start.ps1
```

在服务所在电脑直接打开 `http://127.0.0.1:8000`。第一次打开时，页面会引导你为 `ADMIN` 设置自选密码、绑定认证器并保存恢复码。随后使用 `ADMIN`、密码和动态验证码登录。首次设置只创建这位管理员；需要协作时，管理员可以通过用户管理功能显式添加成员。Windows 会用当前操作系统用户身份保护账号密文，后续启动请使用同一 Windows 用户。

默认的 SQLite 数据库、供应商上传内容、成品和本机密文保存在 `data/`。可在启动前设置 `ECOMMERCE2_DATA_DIR` 指向独立的私有数据目录。安装包、运行数据库和第三方平台授权由各自部署者提供。

首次启动的模型、执行方案和备用列表均为空。管理员可以在模型设置页填写自己的连接和密钥，再选择用于具体任务的方案。本地模型密钥单独保存在运行目录的 `model-credentials.enc`。需要通过环境注入时，手工配置以 `ECOMMERCE2_MODEL_KEY_` 开头的专用变量名。需要官方客户端时，请在页面主动连接和授权；此部署的官方登录保存在仓库根目录下的 `data/official-client/`。

## 第一次使用

1. 在导入中心下载供应商 Excel 模板，阅读示例和字段说明，在「正式填写区」输入自己的商品。从导入预览核对规格与原图。
2. 打开商品档案，确认尺寸、售卖组成和待补字段。配置自己的文本或图片模型后，可以为对应规格生成母稿与销售素材。
3. 在刊登页面新增自己的平台连接，完成类目和字段映射，再按需生成草稿。Amazon SP-API 正式提交取决于自己取得的卖家授权、正确的目标和执行配置；安装后的空数据库没有店铺授权。

商品与交易逻辑在 `app/commerce/`，设计流程在 `app/`，界面在 `app/templates/` 和 `app/static/`。`app/static/templates/` 提供带虚构示例的空白供应商商品模板。

欢迎一起完善供应商导入、计量单位、类目规则、多语言刊登和售后流程。可以先在 Issue 描述一个操作、得到的结果和期待的结果。PR 若修改平台接口或字段转换，请附虚构的输入与期望回执；界面修改可附空数据界面的截图。账号初始化的回归用例可通过以下命令在仓库根目录运行。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_account_setup.py
```
